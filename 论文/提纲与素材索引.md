## 第二章 数据预处理与轮胎衰减建模
- 数据: FastF1 2022–2025 摩纳哥正赛,76 份遥测 CSV(`2022~2025\{DRIVER}\`)
- **清洗口径统一(2026-10-13)**: 异常圈判定收敛到单一模块 `脚本\laps_cleaning.py` ——
  ① 全绿(`TrackStatus == "1"`)是唯一"有效圈"前提;② 拟合链路 `fit_ready()` 剔除
  发车/进站/中性化/重启/离群圈,模拟链路 `sim_ready()` **不删行**(保胎龄连续);
  ③ 离群判定 = 扣燃油效应(0.06s/圈)→ stint 组内**二次去趋势** → 残差 MAD(最小效应量 0.8s);
  ④ 一致性由 `脚本\validate_cleaning.py` 验证 → `图表\15b_清洗口径验证_2024摩纳哥.csv`
  (发车圈 20/20、中性化圈 16/16、重启圈 16/16 全车手一致);
  ⑤ 逐圈状态落盘为 `<年份>\<车手>\<车手小写>_monaco_<年份>_lap_status.csv`(共 80 份)
- 清洗管线: `脚本\fit_tire_degradation.py`(调用 `laps_cleaning`,含燃油修正 0.06s/圈、
  进站出口惩罚校正、旧胎等效胎龄反推)+ `图表\07d_圈次清洗标记明细.csv`(4384 行/3567 参与拟合)
- 三阶段模型: 暖胎 → 峰值 → 线性衰减;产物 `图表\06/07/07b/07c`
- **拟合质量与不确定性(2026-10-20 新增)**: 衰减斜率用**分箱加权**(权重=箱内圈数)最小二乘;
  `07` 增列 R² / R²(衰减段)/ RMSE / **stint 级聚类 bootstrap 95% CI** / 样本 stint 数;
  车手级参数用**收缩估计**(`w = n_eff/(n_eff+30)`,`min_n=15`,衰减率截断到 `[0, 合并 CI 上界]`),
  彻底消除旧的负衰减率。当前值: C5 **11.92 %/100圈**(CI 5.30–16.89)、
  C4 **3.56**(CI 0.32–7.45)、C3 **2.20**(CI 0.16–4.14)
- 圈速波动: `脚本\fit_lap_noise.py` → `图表\14_圈速波动估计.csv`
  (1.5IQR 去尾 σ=0.7357s,正态检验 p=0.0014;分车手 σ 加权,如 LEC 0.79s / VER 0.59s;
  该表亦由统一清洗口径重标定,修复前 σ=1.0547s 且车手级存在 MAG 5.03s/PER 5.30s 失真值)
- 暖胎段物理截断与 perf 归一化(模型合理性,见 `web\engine.py` `_sanitize_deg`/`lap_time`)

## 第三章 基于动态规划的赛前最优策略(问题一)
- 模型: 状态(圈数,配方,胎龄) + 库存约束;每次进站必换配方;胎龄 ≤78(即不设人为上限,见 `strategy_core.MAX_TYRE_AGE`);≥2 种配方(FIA 30.5m)
- 求解器: `脚本\solve_dp_strategy.py` / `web\engine.py` `_solve_inventory`(两者共用 `脚本\strategy_core.py` 的参数与圈速公式)
- 轮胎规则: FIA 2025 Art.30 —— 13 套=2硬+3中+8软,P1/P2/P3 各还 2 套,正赛 ≤7 套
- 结果: `图表\08/08b/08c/09/10b/10c/10d`;1 停基准 **C4(56)→C5(22) = 5922.1 s**
  (与 C5(22)→C4(56) 同秒,镜像解),纯时间最优为 **C4(32)→C5(15)→C4(31) = 5917.3 s**,
  仅快 4.8 s → **一停是稳健选择**;分车手最优见 `10b`(如 HAM C4(64)→C5(14)、LEC C4(32)→C5(46))
- 规则变化: 2025 摩纳哥"至少 3 套胎"= 强制两停口径(`10c/10d`)

## 第四章 基于 Stackelberg 博弈的赛中实时决策(问题二,核心创新)
- 博弈结构: 领导者(先进站)-跟随者(跟/不跟);反应延迟圈 = undercut/overcut 机制来源
- 场景: Undercut / Overcut / SC·VSC(合并) / 红旗(免费换胎+静态发车,FIA 57.4/58.11)
- 蒙特卡洛: 两层随机性(逐圈独立 + 当日状态相关);成功率 = 连续概率
- 指标体系: 成功率 / 得而复失率(被反超风险) / 策略增益(pp vs 不动基线) / 超越圈数分布
- 对手换胎推断: 胎龄 vs 赛程反推进站圈号(`infer_rival_pit_status`)
- AI 策略分析: DeepSeek-V4.1-Flash(`web\ai_config.local.json`,不入库)
- 结果: `图表\11`;Web 赛中决策页(鲁棒性区间、圈速差拆解)
- **2×2 收益矩阵与均衡(2026-10-20 新增)** `图表\19`、`图表\20`:
  - 收益 = **时间层 + 位置层**: 时间层给出终点净时间差(margin),位置层刻画
    "进站让出位置 → 必须在剩余圈内追近并完成超车",单圈超车概率 0.5% + 0.8%/(s/圈)、
    上限 6%(与 `monaco_pass_*` 同一标定);
  - 基准局面(领先 0.8 s、双方 C4 胎龄 30 圈、剩 33 圈):
    (先进站, 对手跟进) 54.0%、**(先进站, 对手不跟) 29.1%**、
    (继续跑, 对手跟进) 72.2%、(继续跑, 双方都不动) 55.0% → **Nash = 双方都继续跑**,
    Stackelberg 解(我方先动)仍是"继续跑",均衡胜率 55.0%;
  - **纯时间模型的反例**: 若忽略位置层,"对手不跟"这一格会算出 91.4% 的反超胜率 ——
    与"摩纳哥几乎无法超车"的现实相反,是本章最需要讲清楚的建模取舍;
  - 均衡区域(90 个"差距 × 胎龄"组合): 胎龄 ≤30 圈时"继续跑"是均衡;胎龄 ≥40 圈
    先进站转为均衡;35 圈附近**只有在落后(差距 ≤1 s)时**才值得先动 ——
    领先时先动等于把位置交出去。可在 Web"数据总览"直接查表。


## 第五章 算法验证与结果分析
- **清洗口径一致性**(2026-10-13 新增) `图表\15b`: 发车/中性化/重启圈判定 20/20、16/16、16/16
  全车手一致;拟合链路剔除异常圈、模拟链路不删行两条语义均成立
- **交叉年份验证** `图表\15`: 留出年 C4 MAE 0.35s/圈、C3 0.77s/圈(2024);
  DP 分割 28/50 跨年一致;分年 deg 波动 -0.32~+0.25 %/圈
- **蒙特卡洛收敛性** `图表\16`: 均值稳定 54.3%,SE ∝1/√N(4.11pp→0.20pp),经验/理论 SE 吻合
- **敏感性分析** `图表\17`: 龙卷风图,磨损系数主导(DP ±30.7s / MC ±5.03pp),策略稳健
- **历史回溯** `图表\18`: 2024 摩纳哥红旗,实测 16/20 车手在重启处换胎;
  **主判据改为确定性时间账**(不换胎保守口径多花 6.7 s、线性外推 176.9 s,
  且"两种配方"规则还需再付一次 19 s 停站)→ 结论「换胎」与实际车队一致
  (原 68.9% vs 6.9% 的 MC 双分支对照因对手动作与自车绑定而双向饱和,已降级为旁证)
- **博弈均衡** `图表\19/20`: Nash = 双方都继续跑,均衡胜率 55.0%;胎龄 ≥40 圈先进站转为均衡
- **工程可复现性(2026-10-20)**: `脚本\run_all.py` 一键整链;`tests\` 30 项不变量
  (含"DP 目标值 == 累计曲线末值"这类曾在无声中出错的断言)
- Web 内置: 每分支鲁棒性扰动区间(衰减±20%/圈速±0.3/差距±2/σ×1.5)
