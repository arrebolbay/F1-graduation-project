高级参数(进站损失 / 换胎分布 / 配方偏移 / 红旗发车)

概率口径: 每圈圈速 ~ N(确定性圈速, σ²),σ 默认按车手实测标定 (图表/14_圈速波动估计.csv,1.5IQR 去尾后 σ≈1.05s 且近似正态), 故成功率/被反超风险为连续概率而非硬判定;手动填 σ 则覆盖为全场统一值。 提示: 摩纳哥轮胎衰减极低,默认参数下 Undercut"对手不跟"分支成功率会非常小, 这是模型对现实的正确反映;若需更直观的演示效果,可增大配方偏移差异 (如 C5=-1.5、C3=+2.5)。

Stackelberg 结构: 领导者先行动(进站或等待),跟随者观察后响应。 每个响应分支独立输出成功率;成功样本中统计"完成超越所需圈数"。
